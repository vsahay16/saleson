## Files and performance

assets/img/clients/master/ contains one WebP per matched identity. by-page/ contains requested convenience copies. Use the same master URLs on the live site for cross-page caching. A homepage strip should load only its chosen 6–8 files, not the complete library. Use fixed logo containers with object-fit:contain, explicit dimensions, lazy loading below the fold and no base64 embedding. Veto’s official white asset needs a dark card.

Original colours and proportions are retained; logos are never invented or recoloured. Source and output dimensions are in the map. Low-resolution originals remain labelled; request vectors for unusually large displays. Files labelled as needing artwork are intentionally not replaced with text pretending to be a brand logo.
